# Brawlhalla Reskin by razenet
![](main.gif)

## 1. Get Started
- Choose a theme in /themes
- Download the folder with the theme
- Open Brawlhalla local files
- Rename the "mapArt" folder to "mapArt.bak"
- Rename the downloaded theme to "mapArt"
- Move it to the brawlhalla root folder
- Done.
